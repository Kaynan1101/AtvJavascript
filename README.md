# Atividades em Javascript e React (Fatec)

Este repositório reúne as atividades e projetos desenvolvidos durante a disciplina de Javascript na Fatec de Presidente Prudente. Mais do que apenas exercícios de programação, este projeto foi um marco fundamental onde comecei a aplicar o versionamento de código com Git e a realizar deploys contínuos com GitHub Pages.

**[Clique aqui para ver a aplicação em funcionamento](https://Kaynan1101.github.io/AtvJavascript/)**

---

### Sobre o Projeto

O objetivo era aplicar os conceitos de Javascript e da biblioteca React na prática, através de exercícios semanais. O repositório está organizado em pastas, onde cada `SEMANA` corresponde a um módulo de aprendizado, mostrando a evolução gradual do conteúdo.

Este foi o primeiro projeto em que utilizei o Git de forma consistente para controlar as versões do meu código.

### Tecnologias e Ferramentas

* **Frontend:**
    * **JavaScript:** A linguagem principal para a lógica dos exercícios.
    * **React:** Utilizado para construir componentes de interface de usuário.
    * **HTML5 e CSS3:** Para a estrutura e estilização das páginas.

* **Versionamento e Deploy:**
    * **Git:** Para o controle de versão do código.
    * **GitHub:** Como plataforma para hospedar o repositório.
    * **GitHub Pages:** Para fazer o deploy automático da aplicação, tornando-a acessível publicamente.
